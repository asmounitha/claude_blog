# My Portfolio Building Journey

A personal blog by **MOUNITHA**, a Computer Science and Engineering student. It records how I set up my tools, practised coding, built a portfolio website and started building an online presence.

## About This Project

This is a single-page blog written in plain HTML, CSS and a little JavaScript. It is written for students and recruiters, so the language is simple and each tool is explained in a few lines.

## What the Blog Covers

1. **About Me**: Who I am and why I started this blog.
2. **Tools & Platforms I Used**: VS Code, Git, GitLens, GCC and Line Editor, with what each one is and why I used it.
3. **Coding Practice**: LeetCode, HackerRank, CodeChef, GeekCode and coding contests.
4. **Portfolio Building**: Steps to create and host a portfolio website on Vercel.
5. **Collaboration & Version Control**: GitHub projects, GitLens and Live Share.
6. **Social Presence**: Instagram marketing and LinkedIn profile building.
7. **Achievements**: Contest participation, solved problems and milestones.
8. **Future Goals**: Data structures, algorithms and safe coding practices.

## Features

- Clean, modern layout with easy section navigation
- Sticky side menu on desktop and a scrolling tab bar on mobile
- Highlights the current section as you scroll
- Light and dark mode that follows the device setting
- Responsive design for phones, tablets and laptops
- No frameworks or build step needed

## Skills Shown in This Project

- HTML, CSS and JavaScript basics
- Responsive and accessible web design
- Version control with Git and GitHub
- Deploying a website on Vercel

## Run It Locally

1. Clone the repository:
   ```
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in your browser. You can also use the Live Server extension.

## Deploy on Vercel

1. Push the project to GitHub.
2. Sign in at [vercel.com](https://vercel.com) with GitHub.
3. Click **Add New**, then **Project**, and choose this repository.
4. Click **Deploy**. Every new push to GitHub updates the site automatically.
